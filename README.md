# Алгоритмы — учебный MVP

Самостоятельная реализация задания на HTML, CSS и JavaScript.

## Что реализовано

- ввод двух чисел;
- сложение и вычитание;
- список имён;
- добавление и удаление элементов;
- выделение выбранной строки;
- нормализация регистра и пробелов;
- поиск лишних символов;
- очистка лишних символов;
- проверка дубликатов;
- навигация стрелками;
- отмена изменения кнопкой и Ctrl+Z.

## Запуск

Откройте файл `index.html` в браузере. Установка зависимостей не требуется.

## Примеры

- `5` и `6` → `5 + 6 = 11`;
- `  инноКЕнТиЙ  ` → `Иннокентий`;
- `Марфа123!` → программа предложит убрать лишние символы;
- повторное имя в список не добавится.
